At a lonely gas station at dusk, a hummingbird the size of a car hovers at the pump, its wings a blur, its long beak dipping toward a spilled soda can. The teenage attendant stands frozen with the nozzle still in his hand while moths circle the buzzing neon signs. `main.ts` reads `entry.jpg` from its own directory, verifies the JPEG magic bytes, the file length and the largest frame dimensions, then writes the bytes out unchanged as `entry.png`.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
