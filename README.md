High above a dark arena hangs a colossal eye forged of cracked gold, looking down as thousands of people raise framed pictures toward it — every frame holding someone's story, every story hoping to be seen. Somewhere in the middle of that vast crowd, one picture catches the light and glows far brighter than all the rest. The entry's program, `main.ts`, validates `entry.jpg` (magic bytes, size, and frame dimensions walked through its marker segments) and writes its bytes unchanged to the output directory.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
