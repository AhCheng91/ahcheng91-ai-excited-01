Late at night in a laundromat, one washing machine's round drum door bursts open. A wall of glowing turquoise ocean water explodes outward across the floor, and a small wooden rowboat with a lit lantern rides the crest as it pours out of the porthole. A boy in a hoodie grips the door frame, a cat leaps clear, and warm hanging bulbs steam over the cold teal water.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
